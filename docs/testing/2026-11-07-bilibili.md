唯一能装的 Homestead，卡在 710 MB 的下载上。

## 1. 怎么采的（可复现）

B 站没有公开的评论导出，走了两个接口：

- 搜索：`/x/web-interface/wbi/search/type`（wbi 签名 + `buvid3` cookie）
- 评论：`/x/v2/reply/main?type=1&oid=<aid>&mode=3&next=<n>`

三个坑，记下来省得下次再踩：

1. 老接口 `/x/v2/reply` 现在**只返回 3 条热评**，`count` 明明写着 1492。要分页必须用 `/reply/main`。
2. `next=0` 会返回 `-352`（风控）；从 `next=1` 开始，用返回的 `cursor.next` 递推。
3. 连续请求会触发 `-352`，要退避（本次 16 个视频 × 3 页，中途被挡了 3 次）。

关键词 5 个（`MC整合包推荐`、`我的世界整合包推荐`、`我的世界 好玩 整合包`、`整合包 测评`、`MC 整合包 生存`），

## 4. 两个真实安装尝试

### 4.1 RLCraft 2.9.3（评论区呼声最高，CurseForge）

素材：`RLCraft 1.12.2 - Release v2.9.3.zip`（51,324,367 字节，187 个文件，1.12.2 Forge）。
ForgeCDN 直链 12.8 秒下完（约 5 MB/s）——同一时刻 Modrinth 只有 58 KB/s，网络本身没问题。

```
$ blockpilot preflight 'RLCraft 2.9.3.zip' --no-host
  verdict   WARN
  mods      187  (resolved 0, unresolved 187)
  ! CF_API_REQUIRED  整合包声明了 187 个 CurseForge 文件，但没有 API key 无法解析名称与兼容性
  exit 0

$ blockpilot deploy 'RLCraft 2.9.3.zip' --root ./mc-rl --instance rl
没有找到可用的 Java 8（本机：无）
可以装一个：blockpilot java install 8
CF_API_REQUIRED: 这是 CurseForge 整合包，下载它的文件需要 CurseForge API key
  exit 1
```

结论：**能查、不能装**，退出码与提示都对，且没有留下半个实例目录（`mc-rl` 不存在）。
这是设计好的边界（ADR-0021），但对 B 站玩家来说就是「最想玩的包装不了」。

### 4.2 Homestead 2.0.1（唯一可装的，Modrinth）

素材：99.3 MB 的 `.mrpack`，清单里 375 个文件（367 模组 + 2 资源包 + 5 光影 + 2 数据包），
下载总量 **710.3 MB**，另有 3153 个 overrides 文件。

预检（真包，364/367 解析成功）：

```
  verdict   WARN
  mods      367  (resolved 364, unresolved 3)
  ! SERVER_ONLY_MOD  Configurable v1.3.1 for mc1.20.1 声明为仅服务端可用
  ! UNVERIFIED_DEPENDENCY  More Enchantment Info (TIo1UXXV) 需要前置模组 Kotlin for Forge (ordsPcFz)
  ! UNVERIFIED_DEPENDENCY  More Enchantment Info (TIo1UXXV) 需要前置模组 Forgified Fabric API (Aqlf1Shp)
  i UNRESOLVED_MOD  ×3（mixintrace / lazydfu / betterthanmending，本地 jar 没有 Modrinth 记录）
```

安装：真实跑了 17 分钟，下到 **41/375（42 MB）**，速度稳定在 20–40 KB/s。
按这个速度 710 MB 要 5 小时，临时改用分片预取 + 哈希校验，让 `deploy` 走
「缓存命中 → 校验 → 解压 overrides → 部署后检查」这一段。到本轮结束预取到
147 个文件（133 MB），仍未完成——**这不是产品缺陷，是这台机器到 Modrinth CDN 的吞吐问题**
（同一时刻 ForgeCDN 5 MB/s、TUNA 23 MB/s，只有 `cdn.modrinth.com` 在 40–400 KB/s 之间抖）。

所以这条只验到一半：包能读、清单能解析、预检给的是 WARN 而不是误判 BLOCKED。
完整安装与启动留到下一轮补。

## 5. 顺手修掉的：依赖提示只有 project id

Homestead 的预检把这条老问题又摆到面前：

```
! UNVERIFIED_DEPENDENCY  TIo1UXXV 需要前置模组 ordsPcFz，元数据里没有兼容版本
需要人工处理
  ? ordsPcFz  找不到兼容当前游戏版本与加载器的版本
```

`TIo1UXXV` / `ordsPcFz` 是 Modrinth 的 projectId，用户既不知道是谁，也不知道该搜什么。

修法（`ProjectNamer` 可选能力，见 `src/core/sources.ts`）：

- `ModrinthSource.getProjectNames(ids)` 批量查 `/v2/projects?ids=[...]`；
- 预检在依赖闭包之后，把「缺失的 id」与「谁需要它」一起查一次；
- `closureToFindings` / `buildRepairPlan` 接受 `nameOf`，文案改成「名字 (id)」，
  **`subject` 仍是 id**（脚本按它反查）；
- 名字拿不到就退回裸 id，判定完全不受影响。

修完同一条 finding：

```
! UNVERIFIED_DEPENDENCY  More Enchantment Info (TIo1UXXV) 需要前置模组 Kotlin for Forge (ordsPcFz)
? Kotlin for Forge (ordsPcFz)  找不到兼容当前游戏版本与加载器的版本
```

名字查出来还解释了这条 warning 的成因：`Kotlin for Forge` 是 Forge 系的前置，
`Forgified Fabric API` 是 Fabric API 的 Forge 移植——这个包把 Forge 生态的东西带进了
Fabric 实例，元数据里当然没有「兼容 1.20.1 + fabric」的版本。属于作者打包时的真实遗留，不是误报。

## 6. 这轮暴露的产品问题

1. **安装面覆盖不到中文社区的实际分发**：B 站评论区 top 10 里 9 个不在 Modrinth。
   CF 只能 `preflight`，网盘包连入口都没有。参考实现要谈「能被复用」，绕不开这条路。
2. `preflight` 对 CF 包给 `WARN` + `0/187 resolved`。从契约看 WARN 说得通（有可执行提示），
   但「什么都没验成」与「验过发现小问题」是两件事，`unknown` 可能更诚实。
   E2E-104 把 WARN 钉死了，改动需要单独决策。
3. Modrinth CDN 对这台机器只有 40–400 KB/s，而同一时刻 ForgeCDN 5 MB/s。
   如果这是普遍现象，`--china` 的 MCIM 值得再测一轮——本次用 MCIM 单个 range 请求拿到 0 B/s，
   没敢下结论。

### 8.1 发现：报告不显示 MC 版本与加载器

CF 包的提示写着「可以先跑 preflight 看 MC 版本与加载器」，但 preflight 的输出里
**根本没有这两项**：

```
BlockPilot preflight
  verdict   WARN
  mods      187  (resolved 0, unresolved 187)
  ! CF_API_REQUIRED ...
```

用户跑完仍然不知道这是 1.12.2 还是 1.20.1。修法：`PreflightReport` 增加 `target`
（`gameVersion` + `loader`，CF 包也读得到），人类可读输出加一行：

```
  目标      1.12.2 + forge 14.23.5.2860
```

### 8.2 发现：1.12.2 只有 Java 21，被说成「多数情况下能启动」

这台机器装了 GraalVM 21（本会话早些时候没被扫到，是 PATH/`JAVA_HOME` 后来才有的）。预检 RLCraft：

```
! JAVA_NEWER_ONLY  没有 Java 8，但检测到更高的 Java 21
  → 多数情况下能启动；若加载器报版本错误，装一个 Java 8
```

**这句是错的**。1.12.2 的 Forge 在 Java 9+ 上起不来（类转换器与类加载行为都变了），
不是「多数情况」。用户会照提示去启动，然后在千行日志里找一个跟 Java 无关的模组背锅。

修法：`need === 8` 且没有精确版本时给 blocker，稳定码 `JAVA_TOO_NEW`：

```
✗ JAVA_TOO_NEW  Minecraft 1.12.2 只能用 Java 8，本机只有 Java 21
  → 1.12 及更早的版本在 Java 9+ 上起不来；装一个 Java 8：blockpilot java install 8
```

同一份 RLCraft 现在 `BLOCKED / exit 2`；落幕曲（1.20.1 要 17，Java 21 可接受）仍是 `WARN / exit 0`——
两条路各自给出了对的结论。

单测 291 → 292（1.12.2 + Java 21 必须 blocker）。
