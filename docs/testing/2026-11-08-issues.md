## 三条值得记住的坑

1. **`\s` 会跨行。** E2E-301 第一版改成 `/日志\s+(.+?\.log)/m` 仍然失败：
   `日志` 先匹配到上一行的「326 行日志」，`\s+` 吃掉换行，于是把「日志  D:\...」整个当成了路径。
   正确写法是行首锚定 + `[ \t]+`。
2. **「进程还活着」不是证据。** 未捕获异常打在渲染线程上时 JVM 不退出，`--stop` 到点
   我们照样 exit 0。只有日志心跳（安静 ≥20 s 且以栈帧收尾）能区分这两种情况，
   而健康但安静的整合包不会被误判，因为第二条判据不成立。
3. **兜底表会盖过模组自己的声明。** BTWCE 在 1.6.4 上要求 Java 17–21，而「MC 版本 → Java」
   推出来是 8。有 mod 声明时必须以声明为准，否则两条建议互相矛盾，用户照哪条都可能装坏。
